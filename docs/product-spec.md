# 一人公司测试 MVP 产品说明

## 1. 目标

只验证三件事：

1. 用户愿不愿意测
2. 用户觉得结果准不准
3. 用户愿不愿意留下联系方式做下一步转化

## 2. 目标用户

- 想做副业/独立，但不知道从哪开始的人
- 有技能，但不会把技能变现的人
- 想用 AI 做一人公司的人

## 3. 页面结构

1. 首页
2. 测试页
3. 结果页
4. 留资页
5. 简版数据页

## 4. 结果类型

- 服务型一人公司
- 内容型一人公司
- 产品型一人公司
- 混合型一人公司

## 5. 测试维度

1. 能力变现方式
2. 表达意愿
3. 销售接受度
4. 风险偏好
5. 长期目标

## 6. 算法

- 12 道题
- 每个选项给 4 个类型加权
- 结果取最高分
- 前两项分差小于等于 2，则判为混合型

## 7. 埋点

当前本地版已记录：

- app_launch
- home_view
- quiz_view
- quiz_start_click
- quiz_answer
- quiz_prev
- quiz_complete
- result_view
- lead_view
- lead_cta_click
- lead_submit

## 8. 下一步建议

- 接入微信云开发
- 将 leads / sessions / events 写入云数据库
- 增加题目流失统计与结果页停留时长
- 接入真实转化链路（企微、表单、私域）
