# 一人公司测试 MVP 产品说明

## 1. MVP 目标

只验证三件事：

1. 用户愿不愿意测
2. 用户觉得结果准不准
3. 用户愿不愿意留下联系方式做下一步转化

## 2. MVP 用户

- 想做副业/独立，但不知道从哪开始的人
- 有技能，但不会把技能变现的人
- 想用 AI 做一人公司的人

不服务所有创业者，只服务这三类核心人群。

## 3. MVP 核心流程

1. 首页：一句话价值主张 + 开始测试
2. 测试页：12 道单选题，3 分钟内完成
3. 结果页：输出 4 类结果之一
4. 留资页：领取进一步方案
5. 简版数据页：查看基础埋点与留资记录

## 4. 四种类型定义

### 服务型

适合：
- 有专业能力
- 愿意直接服务客户
- 想先赚钱

典型模式：
- 顾问
- 代做
- 陪跑
- 咨询

### 内容型

适合：
- 擅长表达
- 愿意长期输出
- 能做信任积累

典型模式：
- 公众号
- 知识产品
- 社群
- IP 变现

### 产品型

适合：
- 喜欢做标准化产品
- 不想强依赖自己一对一交付
- 有一定结构化能力

典型模式：
- 模板包
- 数字产品
- 工具
- 小 SaaS

### 混合型

适合：
- 既能服务，也能表达
- 最适合从服务起步，再内容化，再产品化

这是很多人最现实的路径。

## 5. 12 道测试题

每题四个选项分别对应：
- A = 服务型
- B = 内容型
- C = 产品型
- D = 混合型

计分方式：
- 选一次，加 2 分
- 最终统计四类总分
- 分数最高者为主类型

混合型优先判定条件：
1. 混合型分数最高
2. 前两名分差 ≤ 2 分
3. 用户同时明显偏“先赚钱”又偏“后期产品化”

## 6. 结果页统一结构

每个结果页统一用这 6 块：
1. 结果类型
2. 为什么适合
3. 你的优势
4. 你的风险
5. 7 天行动建议
6. 领取进一步方案
